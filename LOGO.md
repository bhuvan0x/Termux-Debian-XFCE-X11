# PrimeBook Logo

</p>

The PrimeBook mark combines a Linux terminal prompt with a clean desktop-window silhouette.

- **Deep navy:** the Linux workstation and desktop environment.
- **Blue gradient:** the X11 display and modern desktop experience.
- **Terminal prompt:** command-line control and customization.
- **Wordmark:** PrimeBook, the project identity for this Termux + Debian + XFCE setup.

The source artwork is the editable vector file [primebook-logo.svg](primebook-logo.svg). It is included in this repository and may be reused or modified under the repository's [MIT License](LICENSE), subject to the license terms.
